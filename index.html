AI & Software Projects

End-to-end systems I've designed, built, and shipped — from architecture to deployment.

01

Biometric Payroll & HR Management System

Python FastAPI OpenCV Computer Vision Biometrics

Full-stack enterprise backend for HR orchestration — payroll processing, tax computation, and workflow scheduling — powered by a real-time OpenCV biometric authentication layer for spoof-resistant identity verification.

Architecture & Challenges

  • Computer-vision pipeline: frame capture → grayscale preprocessing → face-landmark alignment → spoof-resistant matching
  • Asynchronous FastAPI endpoints ensuring non-blocking I/O under concurrent load
  • Relational database schema as an optimized ledger for employee metrics, attendance, and payroll

Outcome & Results

High-accuracy biometric verification with zero cloud dependency — enabling offline-capable deployment. Clean async API surface handling concurrent HR operations without request queuing bottlenecks.

02

Smart Agro-Climate Decision Support Platform

Predictive Modeling Full-Stack Web Data Parsing Feature Engineering

Interactive full-stack predictive web platform helping farmers and agricultural institutions make climate-aware planting and resource decisions through dynamic, region-specific data models.

Architecture & Challenges

  • Weather-responsive data-parsing algorithms mapping real-time microclimate indicators against localized soil profiles
  • Predictive crop-health analysis models outputting tailored, region-specific planting recommendations
  • Interactive UI with dynamic inputs, visual feedback, and region-aware defaults

Outcome & Results

Actionable, data-driven recommendations bridging the gap between raw climate data and farmer decision-making. Demonstrated end-to-end ML pipeline skills: data ingestion → feature extraction → model inference → user-facing output.

03

Mystica — Advanced Native Android Music App

Kotlin Jetpack Compose Hilt DI Android 14 Audio Engine

Offline-first MP3 player engineered for Android with a modern Kotlin-first codebase — featuring seamless background playback, custom queues, and intelligent audio-routing across Bluetooth and system outputs.

Architecture & Challenges

  • Background audio state machine with lifecycle-aware foreground services for stutter-free playback
  • Android 14 API-compliant runtime permission modules and audio-focus handling
  • Hilt dependency injection for clean, testable, and modular architecture

Outcome & Results

Delivered a polished, production-quality Android app with zero-latency playback transitions and robust background audio control. Demonstrates strong systems-level thinking — resource management, concurrency, and platform API fluency.
